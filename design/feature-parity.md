# 功能对齐清单（audimind → 本地版）

> 目的：UI 之外，把参考产品的功能点逐条登记，作为后续实现的验收清单。
> 依据：studio 画本编辑页的逐控件走查（浏览器实测 DOM / 提示文案）、用户提供的 5 张截图、以及本项目现有代码的只读盘点（CLI 31 个子命令、FastAPI 约 150 条路由、9 个前端视图）。
> 「我们现状」以仓库里真实存在的能力为准：已实现 = 有可运行命令或接口；部分实现 = 有底层但缺一步 UI 或编排；缺失 = 没有对应能力；不适用 = 与单机单用户形态冲突。

## 统计

| 状态 | 数量 |
| --- | --- |
| 已实现 | 38 |
| 部分实现 | 31 |

| **合计** | **84** |

### 最影响日常使用的缺失项（建议优先补）

1. **本章任务面板**：参考把「生成中 / 失败 / 待配 / 一致性」聚合在一个可展开侧栏；我们只有分散的 CLI 输出与 Inspector，用户无法一眼知道「现在卡在哪」。
2. **影响清单确认**：正文或音色变更后，参考会列出受影响的行 / 场景 / 资产并要求确认；我们只做单行过期标记，缺整章影响面。
3. **行级编辑补齐**：拆分行、合并相邻行、批量合并旁白、查找替换、撤销/重做，是画本编辑的高频操作，目前只有改说话人 / 参数。
4. **媒体库状态聚合**：音效/配图/视频的生成本身可用，但没有统一的素材列表、失败重试与素材包导出入口。
5. **通知与任务队列页**：长任务（整本配音、批量出图）缺少集中查看与取消入口。

| 会员 / 订阅 | 权益页、额度、升级入口 | 本地版无账号体系与计费，模型算力在用户本机 |
