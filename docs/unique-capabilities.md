## 五、端到端流程：独有能力叠加位置

竞品原生主流程：**项目 → 章节/画本 → 角色与音色 → 生成配音 → 智能对轨 → 时间轴后期 → 导出**。
下面按界面真实先后顺序把本系统能力叠进去，每一步给出视图入口、能力编号、前置条件、产出物，以及相对竞品步骤的关系。

### 步骤 1　新建 / 打开项目
- **视图与入口**：图标栏「项目」→ 工程列表 `#/projects`；卡片「新建项目 / 打开 / 导入正文」。
- **能力编号**：—（基础流程，复刻项 #1–#8）。
- **前置条件**：本机工程目录可读写。
- **产出物**：工程目录（`project.json`）与空章节目录。
- **与竞品关系**：复刻，不叠加。

### 步骤 2　写作前置段（新增环节）
- **视图与入口**：图标栏「小说」→ `#/p/{path}/novel`；左栏「写作设定 / 世界设定 / 分层大纲」，右侧章详情「章节正文」「流程衔接」。
- **能力编号**：U1 世界设定、U2 写作设定、U3 分层大纲、U4 黄金三章、U5 正文生成与续写、U6 正文→台词→配音衔接。
- **前置条件**：工程已存在；写作模型在「设置 → 写作（omlx）」可用。
- **产出物**：`worlds.json`、故事圣经、幕/章/节拍大纲、章节目录与正文；「流程衔接」卡给出场景 / 台词 / 待补配音计数。
- **与竞品关系**：**新增环节**。竞品从已有文本开始；本步产物（章节与正文）直接成为步骤 3 的输入。

### 步骤 3　章节 / 画本（增强）
- **视图与入口**：图标栏「目录」→ 选章进入画本编辑视图（顶栏第一个视图图标）；工具条「查看原文 / 拆场景 / 批量合并旁白 / 规则标注 / 生成配音」；行尾「⋯」菜单；行内展开编辑。
- **能力编号**：U10 脚本标注、U12 行结构编辑与版本、B1 导演脚本规则标注；U6 在此承接（小说视图的「去画本」）。
- **前置条件**：章节已有正文（步骤 2 生成，或工程卡「导入正文」）。
- **产出物**：场景与台词行（待配 / 已过期）、逐行情绪 / 强度 / 停顿 / 说话人；导演标注文本与告警三级定位（场次 · 台词序号 · 说话人）。
- **与竞品关系**：**增强竞品章节 / 画本**。竞品侧重文本切分，这里补行内表演参数、合并 / 拆分、版本记录与规则标注。

### 步骤 4　角色与音色（增强）
- **视图与入口**：图标栏「角色」`#/p/{path}/characters`（顶部「一致性」「AI 生成角色」「自动推荐音色」；档案卡「AI 补全」「形象图」）；图标栏「音色」`#/p/{path}/voices`（顶部「音色设计」；勾选后「候选对比」）。
- **能力编号**：U7 角色档案与形象提示词、U8 一致性规则矩阵、U9 候选音色对比、B2 AI 生成 / 补全档案、B3 角色形象图、B4 音色克隆 / 设计、B5 自动推荐音色。
- **前置条件**：步骤 3 已切出台词行（角色由说话人识别，含旁白 / 未识别）；B2 / B3 / B4 需要写作模型或 ComfyUI / 本机音色设计环境。
- **产出物**：`characters.json` 的角色档案、形象图与音色绑定；音色设计候选与批次记录；缺音色清单与规则检查结果。
- **与竞品关系**：**增强竞品角色与音色分配**。并排对比、规则矩阵、AI 建档与全剧编排替代逐个试听、人工核对。

### 步骤 5　配音（增强）
- **视图与入口**：画本编辑工具条「生成配音」；右栏「本章任务」；图标栏「任务」`#/p/{path}/tasks`。
- **能力编号**：U13 批量配音与任务控制、U14 GPU 锁与并发明细。
- **前置条件**：台词行已绑定音色（步骤 4 完成）。
- **产出物**：`assets/voice/lines/*.wav`，行状态变为已配；队列快照与 GPU 锁明细。
- **与竞品关系**：**增强竞品配音执行**。一键补齐、影响清单确认、暂停 / 继续、失败行单独重试。

### 步骤 6　音效 / 配图 / 视频 / BGM 生成（新增环节）
- **视图与入口**：图标栏「素材」`#/p/{path}/media`；顶栏「生成本章音效 / 配图 / 视频」；每条音效「生成 / 重生成」；「BGM」标签内的生成表单。
- **能力编号**：B6 音效 / 配图 / 短视频 / BGM 生成。
- **前置条件**：步骤 3 已切出场景与台词行（音效按行、配图 / 视频按场景、BGM 按本章）；配图 / 视频需要 ComfyUI 在线，BGM 需要本地 Stable Audio 或 ACE-Step。
- **产出物**：`assets/sfx|image|video/*` 与 `assets/audio/bgm/*`；BGM 生成记录与 cue。
- **与竞品关系**：**新增媒体生产环节**。竞品不产出这些素材；本步产物在步骤 8 时间轴与步骤 9 导出中使用。

### 步骤 7　对轨与审听（质检环节）
- **视图与入口**：画本顶栏「更多视图」→「智能对轨」；「更多视图」→「内容审听」落到画本右栏「智能审听」页签。
- **能力编号**：U11 智能审听；#88 为必然差异（本地静音切分 + 行数一致性校验），不属独有能力。
- **前置条件**：本章已配音；对轨需要一段整章人声录音（MP3 / WAV / M4A）。
- **产出物**：语速异常行清单；人工录音按行写入 `assets/voice/lines/{line}_r{rev}.wav`，并自动重建时间轴。
- **与竞品关系**：**新增质检环节**；智能对轨**替代**竞品云端 ASR（原因见第四节）。

### 步骤 8　时间轴后期（复刻）
- **视图与入口**：画本顶栏视图切换「后期制作」；轨道 S / M、音量、条目拖动、淡入淡出、查看标记。
- **能力编号**：—（复刻项，无独有能力叠加）。
- **前置条件**：步骤 5 / 7 已有音频；步骤 6 的素材可插入轨道。
- **产出物**：本章时间轴（timeline）。
- **与竞品关系**：复刻，保持 1:1，不叠加。

### 步骤 9　导出（增强）
- **视图与入口**：章节目录行「⋯」→「下载音频」→「分轨与工程包」→ 导出页 `#/p/{path}/export/{chapter}`。
- **能力编号**：U15 导出预检与剪映草稿。
