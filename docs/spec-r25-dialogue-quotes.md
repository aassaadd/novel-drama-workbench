# spec-r25 正文对白统一使用中文全角双引号 “”

## 问题

生成正文时人物对白引号不统一：实测出现 `「」`、`『』`、`【】`（截图）与英文 `""`，
台词切分只认 `“”`/`「」`/`""`，`【】` 会被当成旁白，导致对白丢失。

## 规则

1. 提示词硬性规则（正文生成、续写正文、批量/编排生成共用同一收口）：
   - 人物对白一律用中文全角双引号 `“”`；
   - 禁止 `「」`、`『』`、`【】`、英文 `""` 与单引号；
   - 禁止不加引号直接成段写对白；
   - 旁白、心理描写不加引号。
2. 生成后规范化 [dialogue.py](../src/novel_drama/text/dialogue.py) `normalize_dialogue`：
   - 成对的 `「」`/`『』` → `“”`；
   - 整行只有一个 `【…】`（截图里的写法）→ `“…”`，行尾标点保留；
   - 包住中文的英文 `"…"`/`'…'` → `“…”`；
   - **只改引号字符**，其它标点、空格、换行原样保留；数量不平衡的引号不猜配对。
3. 漏引号检查：已知角色名 + 冒号开头且整行没有中文引号时，记一条
   「第 N 行疑似对白未加引号，请人工确认」，不改写正文。
4. 下游台词切分 `_QUOTE_PATTERN` 增加 `『』`、`【】` 兜底（旧正文仍可切分），
   `“”` 为首选；嵌套在 `“…”` 内的 `『』` 不会被拆成两段对白。

## 生效范围

- 正文生成：`service.generate_chapter`（单轮/多轮）生成后统一规范化，返回值新增
  `dialogue_warnings`；
- 续写正文：`continuation.continue_chapter` 每轮 segment 规范化后再拼接/落盘，
  提示并入 `warnings`（预览弹窗可显示）；
- 批量生成 / 自动编排：`orchestration.produce` 走 `generate_chapter`，自动生效；
- 页面：正文生成完成时若有漏引号提示，额外 toast 提醒人工确认。

## 兼容性

- 不改任何 schema，不改其它排版约定；
- 只做字符级替换，不重写句子；漏引号不自动补；
- 已规范化的 `“”` 内容保持不变。

## 验证

- 桩：`「你来了」`、`『走吧』`、整行 `【…】`、英文 `"…"`/`'…'` 均变为 `“…”`；
  `“”` 保持不变；去掉引号字符后的正文与原文完全一致（空格/换行未动）；
  `沈砚秋：执照可以收。` 触发人工确认提示且正文不变；
- 切分：`沈砚秋：“你来了。”`、`他说：“我知道『那件事』。”`、`顾老板：【好懂啊！】`
  均能切出对白，旁白仍归旁白；
- `python -m compileall -q src`、`node --check page-chapter.js` 通过；未启动服务、未做浏览器实测。
