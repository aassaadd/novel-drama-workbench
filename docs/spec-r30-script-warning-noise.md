# spec-r30 导演标注告警降噪

## 目标

导演标注的告警从「45 条刷屏」降到「0 条硬告警」，让可自动修复的问题不再打断流程。

## 说话人归一化

新增 `text/names.normalize_speaker_name` / `match_speaker`（标注解析共用）：

- 去项目符号与 `*`（「* 一品」→「一品」）、去括号及内容（「沈砚（主角）」→「沈砚」）、
  去引号、去全部空白、去「说/道/问/答」等后缀（「沈砚说：」→「沈砚」）；
- 先精确匹配姓名/别名，再做长度 ≥2 的前缀互含（覆盖简称）；
- 解析不到的脏名字不再因符号差异落到 `chr_unknown`。

## 提示词收紧

- 基础 prompt 带上角色表（`_project_context(..., characters)`），说话人只能从表里取；
- 明令不得自造、加 `*`/编号/括号、写「未知」；
- 「（未标注）」的行先按上下文推断说话人，确实无法判断才留空写「：台词」；
- 场景块不再把未识别说话人渲染成「未知」，旁白渲染「旁白」，其余渲染「（未标注）」。

## 音效序号与解析容错

- `after-line=N` 超出本镜头行数：夹紧到末行，只记普通日志并合并为信息级；
- 序号 0/负数、镜头不存在：保留硬告警；
- 模型常见别写自动归类（信息级）：音效 `silence/none/ambient`→ambience、`effect/effects/sfx`→foley、
  `bgm/music`→music_sting、`whoosh`→transition；无关键图的 `i2v` 退化为 `t2v`，不再整章解析失败。

## 告警分级

- 可自动修复的提示统一加前缀 `【已自动修正】`，同一镜头同一原因合并为一条并带「共 N 处」计数；
- `director-script.warnings` 结构不变（不改 schema），
  脚本/镜头 `status` 只由「非信息级」告警决定，信息级不再让脚本变 draft；
- CLI 摘要区分「告警 N 条，已自动修正 M 项」；
- 标注页告警区拆两段：硬告警直接列出；信息级折叠为「已自动修正 N 项」。

## 重新标注修旧行

`_apply_script_to_chapter` 新增兜底：新台词行没有命中旧行 ID 时，若同场景存在同文本（忽略空白与首尾引号）
的 `chr_unknown` 行，则更新该旧行（说话人/情绪/类型/文本）并复用原 ID，不新增行，
TTS 状态按原逻辑置 stale。

## 验证

- 桩：脏名字 8 种写法归一化正确；`* 一品`/带括号/简称均映射到正确 ID；越界音效合并一条（共 2 处）且无硬告警；
  序号 0 保留告警；`silence` 归 ambience；缺关键图 i2v 退化 t2v；重新标注旧 `chr_unknown` 行时
  `lines_added=0`、`lines_updated=1` 且复用旧 ID。
