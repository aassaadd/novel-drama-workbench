# audimind 本地复刻 · 功能规格与实施计划

> 目标：在本地完整复刻 audimind（万象有声）的产品形态与功能集合，底层替换为本机能力（现有 CLI / FastAPI / IndexTTS / CosyVoice3 / Stable Audio / ComfyUI / omlx）。
> 范围：除会员、订阅、付费、团队协作、评论、权限、多用户外，功能与交互对齐参考产品。
> 验收清单：`design/feature-parity.md`（84 个功能点）。
> 分支：`feature/audimind-local-clone`（从当前 HEAD 创建，工作区未提交改动保留）。

## 1. 结论摘要

| 项 | 结果 |
| --- | --- |
| 功能点总数 | 84 |
| 已实现 | 38 |
| 部分实现 | 31 |
| 缺失 | 15 |

## 4. 功能实现方案（按模块）

### 4.1 工程管理
- 复用：`ndw init`、`project list/info`、`chapter import`、`/api/projects`、`/api/project/delete`。
- 新建：`GET /api/workspace/usage`（遍历工程目录汇总占用）、`POST /api/project/copy`（目录复制 + 重新索引）。
- 前端：卡片网格、搜索/排序/视图切换全部在前端完成，不新增查询接口。

### 4.2 目录与章节
- 复用：`/api/project/chapters`、`chapter add/delete/save/edit`、`scene split`、SSE 生成。
- 新建：`GET /api/ui/chapters/filter?scene=&character=&status=`（在现有 chapters 结果上过滤）；`POST /api/ui/chapter/split-preview`（包一层 `scene split --dry-run` 并返回 diff 结构）。
- 前端：目录行、三组筛选、拆场景 diff 卡。

### 4.3 画本编辑与台词行
- 复用：`/api/ui/lines`、`line/set`、`line/set-batch`、`line/rerun`、`line/revert`、`line/versions`、`line/diff`。
- 新建（后端，均为纯文本/参数操作，不碰模型）：
  - `POST /api/ui/line/merge`：合并相邻行（拼接 text、取首行 speaker、合并停顿）。
  - `POST /api/ui/line/split-one`：按光标偏移拆行，写入 `split_from`。
  - `POST /api/ui/line/merge-narration`：按期望字数合并相邻旁白，返回预览后再提交。
  - `POST /api/ui/line/replace`：范围内查找替换，返回命中数，支持全半角与逐条确认。
- 前端：行组件（说话人 200 / 正文 / 行内标签 / 行首播放 / 行尾更多）、行内展开编辑、撤销重做命令栈、快捷键层、隐藏标签与字号开关。

### 4.4 角色与音色
- 复用：角色 CRUD、SSE 生成、`cast/check`、`cast/autofill`、`cast/fill`、`voices/*`、`voices/design/*`、`voices/casting/*`。
- 新建：
  - `GET /api/ui/characters/{id}/references`：删除前返回引用行位置（补 48 项）。
  - 推荐打分解释：在 `cast_autofill` 的返回值里补 `reason` 字段（性别/年龄/风格命中），不新增服务。
- 前端：角色列表 + 档案表单 + 音色绑定卡 + 候选对比弹窗。

### 4.5 生成与进度（含任务面板）
- 复用：`tts plan/run`、`tts/batch-all/plan|progress`、SSE、`/api/ui/stop`、`queue list/retry/cancel`、`gpu_queue`。
- 新建模块 **task_board**（后端，无状态聚合）：
  - 边界：只读聚合 `line_state` + `queue.json` + 最近 run 记录，不写入业务数据。
  - 接口：`GET /api/ui/tasks/board?chapter=` 返回 `progress / failed[] / blocked[] / consistency[] / stats`。
  - 依赖：`tts/line_state.py`、`orchestration/gpu_queue.py`、`.ndw/runs/*.json`。
- 新建模块 **impact**（影响分析）：
  - 边界：输入变更对象（章节正文 / 角色音色 / 场景拆分），输出受影响 scene / line / asset 列表与建议动作。
  - 依赖：chapter JSON 内嵌结构 + 行状态；不引入图数据库。
  - 接口：`POST /api/ui/impact/preview`、`POST /api/ui/impact/apply`。

### 4.6 审听与一致性
- 复用：`timeline build/show`、`mix`、`cast/check`。
- 新建：**consistency 规则集**（同场景同角色音色一致、旁白全剧单一音色、角色跨章一致、未绑定音色、参考音时长异常），输出为 `task_board` 的 `consistency` 段；不调用模型。
- 「智能审听」本身（AI 质量评估）不在 P0-P2 范围，P3 再做规则版（响度、静音段、时长偏差），避免引入新模型服务。

### 4.7 媒体
- 复用：`/api/ui/media`、`media/run`、`sfx/generate`、`bgm/generate`、`bundle`。
- 新建：媒体聚合视图（前端）+ `GET /api/ui/media/summary`（按分类/状态计数）。
- 占位降级必须在 UI 标注：非 ComfyUI 时的配图为色块、视频为静音 MP4。

### 4.8 导出
- 复用：`produce`、`mix`、`mux`、`export --format mp4|mp3|srt|manifest|bundle|jianying`、`/api/ui/exports`。
- 新建：`POST /api/ui/export/preflight`（缺 TTS 行、缺音色角色、视频超时、音效缺失），返回问题清单与可忽略标记；沿用 `bundle` 的 `missing` 逻辑。

### 4.9 通知与任务
- 复用：现有 SSE 与 job 记录。
- 新建：**notifications**（本地事件表 `.ndw/notifications.json` + `GET/POST /api/ui/notifications`）；队列页直接消费 `queue list` 与 SSE 进度。
- 前端：Alt+T 通知面板、快捷键面板、全局搜索（先用文件名/标题级搜索，P3 再考虑 SQLite FTS）。

### 4.10 设置
- 复用：`/api/config`、`/api/ui/models`、`models/install`、`settings/model-limits`、`comfy/health`、`ndw doctor`。
- 新建：无。仅补前端表单与「测试连接」按钮的状态展示。

## 6. 数据模型差异

| 实体 | 现状（已有） | 复刻需要 | 处理方式 |
| --- | --- | --- | --- |
| project | work 元数据、settings、logline | 封面、统计缓存、最近打开 | 追加可选字段 `cover`、`stats`、`lastOpenedAt`；旧工程可缺省 |
| chapter | content、outline、scenes[]、sfx_events、key_images、video_segments | 章节级状态汇总 | 不落盘，由 task_board 计算 |
| line | speaker、text、kind、emotion、intensity、speed、pause、state | 拆分来源、合并组、行内标签 | 追加 `splitFrom`、`mergeGroup`；标签复用现有字段 |
| character | 档案全字段、voice_binding、voice_profile | 推荐理由 | 仅在接口返回 `reason`，不入库 |
| voice | variants、reference、prompt_cache | 候选评分 | 接口计算 |
| timeline | tracks/items/markers | 选区与人工微调草稿 | 追加 `draft` 段，写回前需确认 |
| 通知 | 无 | 本地事件 | 新增 `.ndw/notifications.json` |
| 任务 | queue.json（仅 TTS 可执行） | 统一任务视图 | 不改变 queue.json 结构，聚合层读取 |

## 7. 分阶段实施计划

### P0 · 骨架与主链路（可日常使用）
- 范围：`web-next` 外壳（顶栏 / 图标栏 / 上下文面板 / 右栏 / 底栏）、工程列表、章节、人物、音色库、画本编辑（只读 + 改说话人/参数/批量）、导出（现有格式）、设置。
- 验收：在 1280 与 1440 下可完成「打开工程 → 选章 → 改台词 → 生成配音 → 导出 MP3」全流程，与参考页并排无明显结构差异。

### P1 · 编辑增强与任务可见性
- 范围：本章任务面板（task_board）、生成参数弹窗、失败重试与版本回滚收敛到行内、候选音色对比、媒体库、导出前完整性检查、缺音色引用保护。
- 验收：`design/feature-parity.md` 中 P1 条目全部通过；生成中能看到逐段进度并可停止；失败项可在行内重试。

### P2 · 效率与批处理
- 范围：合并/拆分/批量合并旁白/查找替换、影响清单确认、队列页、通知中心、工程卡封面与搜索排序、剪映导出、BGM、一致性规则。
- 验收：单章 30 段以上的编辑操作可在不离开键盘的情况下完成；上游变更会给出影响面并要求确认。

### P3 · 锦上添花
- 范围：时间轴编辑（裁剪/缩放/选区）、规则版审听、快捷键面板、右键菜单、隐藏标签、字号、全局搜索、配置导入/恢复默认。
- 验收：与参考页逐控件对照，除排除项外无「参考有、我们没有」的入口。

## 9. 风险与不做的事

- 不改现有 `src/novel_drama/web/static`，新前端独立目录，随时可回退。
- 不新增服务、不引入云依赖；模型调用仍走本机子进程 / ComfyUI。
- 不实现多用户、权限、评论、同步——与本地单机形态冲突。
- 队列目前只真正执行 TTS；媒体走 `produce` 直调。复刻「队列页」时按真实能力展示，不伪造任务状态。
- 生成类操作的失败必须暴露真实错误码，不用占位成功。

## 10. P0 主链路操作路径对照（入口 → 步骤 → 结果）

> 口径：操作逻辑对齐参考，不按旧界面习惯改写步骤；参考没有的主路径不自行发明。
> 本表同时作为 P0 验收清单，实现见 `web-next/`，挂载在 `http://127.0.0.1:<port>/next/`。

### 10.1 打开工程

| # | 参考 | 我们的实现 |
| --- | --- | --- |
| 入口 | 顶栏「返回」→ 工作区首页 | 顶栏左侧返回按钮 → `#/projects` |
| 步骤 | 1. 首页点工程卡片的「打开」 | 1. 点工程卡片任意位置或底部「打开」 |
| 步骤 | 2. 进入编辑态，默认落在上次章节 / 首章 | 2. 取 `GET /api/project/chapters` 后进入第一章 |

| `sfx_to_dialogue` / `sfx_to_narration` / `sfx_to_sfx` | ms | 0–10000 | 音效提前/滞后摆放时与台词、相邻音效的间隔 |
| `silences_ms.end` | ms | 0–10000 | 整章末尾静音，计入时间轴总时长 |
| `audio.format` | — | mp3 / wav / m4a | 交付包整章音频格式 |
| `audio.sample_rate` | Hz | 44100 / 48000 | 时间轴 `sample_rate`（保存时同步 `output.sample_rate`）、导出转码 |
| `audio.bitrate_kbps` | kbps | 192 / 256 | 导出有损格式与混流 `-b:a` |

- 存储：`project.json` 的 `settings.production`；旧工程读取时逐项回退默认值（默认 1.0 / 0.8 / 0.4 / 0.4 / 0.3 / 0.3 / 0.3 / 0.25 / 0.3 / 0.3 / 0.2 / 1.0 s，mp3 / 48000 / 192）。
- 接口：`GET/POST /api/ui/project/production`；前端在「项目设定 → 制作要求」自动保存（输入 500ms 防抖、下拉立即保存）。
- 生效链路：`timeline_builder` 计算行间与音效间隔 → `concat` 按时间轴时长裁切/补齐 → `bundle.export` 按格式/采样率/码率转码 → `mux` 使用设置码率。实测开始留白 2.0s、结束留白 1.2s 写入时间轴；m4a 导出为 aac 44100Hz、wav 为 pcm_s16le 44100Hz。

#### 12.13.3 后期轨道控件
- 配音轨按角色拆分（`配音：旁白`、`配音：角色名`），与原「音效 / 音乐 / 视频 / 画面」并列为独立轨。
- 每轨 S 独奏、M 静音、音量滑杆（−24 ~ +6dB，预览即时生效，条目 `gain_db` 与轨道音量叠加）；有独奏时只听独奏轨。
- 吸附：点击刻度时吸附到最近的时间刻度或音频块边界（10px 阈值）；联动：点音频块选中同时间范围的其它轨块并高亮，播放头落到该块起点；查看标记：弹窗列出场景标记并可定位。
- 参考没有切割 / 删除按钮，本地同样不提供。

#### 12.13.4 智能对轨
- 入口：顶栏「更多视图」→「智能对轨」。
- 表单：选择要对轨的播音（固定当前作品）、起始 / 结束章节、上传 MP3/WAV/M4A（≤100MB）。
- 处理：ffmpeg 转 48kHz 单声道 → `silencedetect`（−35dB / 0.35s）切分 → 与所选章节台词行顺序对应；数量一致时逐行写入 `assets/voice/lines/{line}_r{rev}.wav`，`tts.adapter=human`，旧版本保留，已有时间轴自动重建。
- 数量不一致时不写入，任务标记失败并给出切分/行数，可调整章节范围重试；任务记录在 `.ndw/align_tasks.json`，可删除。
- 接口：`GET /api/ui/align/tasks`、`POST /api/ui/align/upload`、`POST /api/ui/align/tasks/delete`。

**验证**：Playwright（127.0.0.1:8790，/tmp/ndw-proj）——顶栏 3 图标 + 更多视图菜单、智能对轨上传页与空态、内容审听右栏页签、制作要求 12 项与 3 个下拉自动保存并持久化、后期按角色分轨 + S/M + 滑杆 + 标记弹窗、录音底部 transport 与查看原文弹窗；全程控制台 0 报错。接口层另测：production GET/POST 回填、时间轴首尾留白与 sample_rate 同步、m4a/wav 转码参数。

### 14.3 边界与约束

- 世界/地点/名词沿用 `schema/world.schema.json` 与 `setting-bible.schema.json`，前端只做文本与对象互转，不新增字段。
