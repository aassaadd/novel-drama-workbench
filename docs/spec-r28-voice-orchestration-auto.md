# R28 音色编排「自动化 + 人工调整」设计

状态：已实现（静态检查 + 桩验证；未启动服务）  
适用范围：`ndw serve` 音色库页、`cast` 编排、按角色生成音色  
关联：`docs/spec-r17-voice-design.md`、`cli_cast.py`（R18 编排检查）、`schema/chapter.schema.json`（`voice_overrides`）

## 1. 目标与原则

- **默认自动**：打开音色编排，先给一张「角色 → 音色」建议表，一键预览、一键应用，不需要逐角色手工挑。
- **随时可改**：每一行都能下拉替换；自动结果不是黑盒，给出匹配理由。
- **只突出异常**：默认只展示需要人处理的行（未绑定、音色缺失、性别不一致、跨章不一致、音色重复过多），正常行折叠低调显示。
- **可回退**：自动编排、自动生成都写撤销日志，至少能撤销最近一次。
- **复用既有机制**：候选批次、流式进度、入库校验、`voice_overrides` 与龙套 `stock.voice_slot` 全部沿用，不另造数据结构。

## 2. 默认路径（用户只需两次点击）

1. 音色库 → 「音色编排」卡片：打开即请求 `overview`，默认筛选「需要处理」，顶部显示「共 N 个角色，需要处理 M 个」。
2. 点「预览自动编排」：后端按规则算出每个角色的建议音色、理由、以及将跳过的角色；表格行内展示「建议：音色（理由）」。
3. 点「按建议填充全部」：确认后只写入有变化的角色绑定与章节覆盖；写撤销日志；刷新总览。
4. 若结果不满意：单行下拉替换，或点「撤销上一次自动编排」回到应用前。

自动生成音色仍走「一键批量生成音色」：已有音色跳过、按角色设定自动带入性别与描述、自动采用第 1 条候选；批量任务写入同一套撤销日志，页面提供「撤销上一次自动生成」。

## 3. 自动匹配规则（确定性、可解释）

输入：角色档案（`gender`、`age_range`、`role`、`personality`、`background`、`speech_style`、`stock`）、音色库（`gender`、`tags`、名称、变体状态）、现有绑定与章节 `voice_overrides`。

### 3.1 旁白（fixed）

- 优先使用设置 `tts.cast.narrators` 中指定的旁白 persona；其次使用旁白角色当前的 `voice_binding`。
- 旁白不参与普通打分、不进入龙套池；未配置且未绑定时标记为问题「旁白未指定固定音色」。

### 3.2 龙套 / 路人（minor）

- 按 `(gender, 年龄段)` 归入同一「龙套音色池」，池内角色复用同一音色，保证跨章节不串音。
- 年龄段由 `age_range` 归一为 `child / youth / adult / middle / senior`。
- 池映射落盘 `assets/voice/casting.json` 的 `minor_pool`，键为 `gender:age_band`，值为 `voice_id`；池里已有音色时直接复用，没有时按 3.3 的打分选一个并记住。
- 已有 `stock.voice_slot` 且与 `(gender, age_band)` 一致的龙套保留原池，不重复计算。

### 3.3 普通角色

硬过滤：角色性别为 `male/female` 时，只考虑同性别音色；角色性别为 `other/unknown` 时不硬过滤，但同性别缺失时降权。  
打分项（总分高者胜，平分按音色 ID 升序保证确定性）：

| 维度 | 规则 | 分值 |
| --- | --- | --- |
| 性别 | 与角色一致 | +40（硬过滤命中即得） |
| 年龄感 | 年龄段一致 / 相邻 | +20 / +8 |
| 身份标签 | 音色 tags 命中角色定位（主角/配角/反派等） | +10 |
| 口音 | `speech_style.accent` 与音色 tags/名称匹配 | +8 |
| 音区 | `speech_style.pitch` 与音色 tags 匹配 | +5 |
| 复用惩罚 | 已被其他角色使用 | 每角色 -15 |
| 来源 | 本工程生成（`source=designed`）优先于内置 | +3 |
| 可用性 | 变体 `status != ready` 或无变体 | 直接排除 |

### 3.4 章节覆盖（`voice_overrides`）

- 解析层只认旁白与带 `stock` 的龙套的章节覆盖；普通角色的残留覆盖会被忽略，因此不参与自动改写。
- 自动编排对可覆盖角色处理「覆盖不一致」：
  - 同一角色在多个章节的覆盖 `voice_id` 不同 → 问题「跨章不一致」。
  - 覆盖与全局绑定不同 → 建议把覆盖对齐到全局（预览中给出，应用时写入，同时清掉失效的 `variant_id` / `persona_id`）。
- 覆盖变化同样写撤销日志；同一章节只快照一次，避免撤销回到中间态。

## 4. 问题行定义（默认只展示这些）

| 类型 | 判定 |
| --- | --- |
| 未绑定 | 角色无 `voice_binding`（旁白按 persona 单独判定） |
| 音色缺失 | 绑定的 `voice_id` 不在音色库，或音色无可用变体 |
| 性别不一致 | 角色与音色性别均为明确值且不同（`other` 不参与） |
| 跨章不一致 | 旁白 / 龙套（带 `stock`）在多个章节的 `voice_overrides.voice_id` 不同，或与全局绑定不一致 |
| 音色重复过多 | 同一音色被 > 3 个非龙套角色使用（龙套池不计） |
| 龙套池缺失 | `minor` 角色对应 `(gender, age_band)` 无池音色 |

正常行默认折叠为一条「其余 N 个角色正常」的摘要，可展开查看。

## 5. 页面交互（音色库）

页面只有一个主视图，其余入口折叠：

```
[主卡片] 角色 → 音色编排
  先看建议，再一键应用；要精调就点某一行的「调整」展开候选；所有自动动作都能撤回
  搜索：角色名 / 音色名   筛选：[需要处理 ▾]
  [预览建议（不改数据）] [一键应用全部建议（可撤销）] [撤回上次自动编排] [为未绑定角色生成音色]
  共 N 个角色，需要处理 M 个
  角色      定位   问题标签      当前音色下拉   建议/状态                  [调整]
  林墨      主角   [未绑定]      （未绑定 ▾）   建议：清亮少年音（…）      [调整]
  └─ 展开后就地显示：音色描述、性别（自动带入）、候选条数、
     [生成候选并自动采用第 1 条] [按档案重新生成描述] [清理本次候选（不影响已采用）]
     状态文案 / 历史批次 / 候选卡片（采用、改选、单条重试）
  另有 N 个角色已正常，切换筛选「全部角色」可查看。

  [为未绑定角色生成音色] 展开的批量面板：
    范围 / 章节 / 候选数 → [查看会生成哪些角色（不开始）] [开始批量生成]
    [继续上次未完成] [重试所有失败角色] [撤回上次自动生成（音色保留在库）]
    逐角色条目（含「查看并改选候选」）

[折叠区] 音色素材与录音（手动维护）
  内置音色 / 我的音色 / 添加参考音色（录音、上传）
```

- 主卡片是唯一主视图；单角色生成、批量生成、候选改选、撤销、搜索筛选、跨章不一致提示都收进主卡片，页面不再并列四张卡片。
- 行状态：有问题（高亮 + 问题标签）、正常（低调 `muted`）、建议与当前不一致（加「待对齐」标签）。
- 下拉替换立即落盘，写撤销日志（kind=`manual`）。
- 「一键应用全部建议」= 应用预览中所有 `suggestion != current` 的行；点击后弹确认，确认才落盘（仍可撤销）。
- 「撤回上次自动编排」只回滚最近一条 `kind=casting` 日志；批量生成的 `kind=generation` 由「撤回上次自动生成」回滚。
- 「为未绑定角色生成音色」展开面板时自动执行一次范围统计，不直接开始生成。

## 6. 生成简化

- 批量生成音色沿用 R28 之前的实现：默认「未绑定音色的角色」，逐角色串行、自动带入性别与描述、自动采用第 1 条。
- 页面不再要求逐角色手填；「按角色设定生成音色」保留为精调入口（可改描述重抽）。
- 批量任务每个角色采用候选时写入撤销日志（kind=`generation`），记录采用前的绑定；「撤销上一次自动生成」恢复这些绑定（生成的音色保留在库中，可手动清理）。

## 7. 撤销日志

文件：`assets/voice/undo/<timestamp>-<rand>.json`

```json
{
  "id": "undo_...",
  "kind": "casting | generation | manual",
  "created_at": "...",
  "characters": [
    {"character_id": "chr_...", "voice_binding": {"voice_id": "..."} | null}
  ],
  "chapters": [
    {"chapter_id": "chp_...", "voice_overrides": {"chr_...": {"voice_id": "...", "reason": "..."}}}
  ]
}
```

- 应用前记录「变更前」快照；撤销时按快照恢复，并从 `undo/` 目录移除该日志（一次性）。
- 只保留最近 20 条，超出按时间删除最旧。
- 批量任务失败/中断不影响已写日志；撤销只回滚已落盘的角色。

## 8. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ui/voices/casting/overview?path=&q=&filter=` | 统计、问题行、正常行摘要、下拉选项、撤销状态 |
| POST | `/api/ui/voices/casting/preview` | `{path}` → 每个角色的建议、理由、变化项、跳过项 |
| POST | `/api/ui/voices/casting/apply` | `{path, character_ids?}` → 应用预览（或指定角色），写撤销日志，返回最新总览 |
| POST | `/api/ui/voices/casting/bind` | `{path, character_id, voice_id}` → 单行替换，写撤销日志 |
| POST | `/api/ui/voices/undo/last` | `{path, kind?}` → 撤销最近一条（可按 kind 过滤）并返回恢复结果 + 最新总览 |

## 9. 非目标

- 不做基于语义向量的音色相似度（规则可解释优先）。
- 不改音色库 schema；绑定仍写 `character.voice_binding` 与 `chapter.voice_overrides`。
- 不自动删除生成的音色；撤销只恢复绑定。

## 10. 验证计划（不启动服务）

- Python 桩：构造多角色 + 音色库 + 章节覆盖，断言：旁白固定、龙套同池、普通角色按分数匹配、复用惩罚、问题行分类、应用后绑定正确、撤销恢复原绑定、日志只保留 20 条。
- 前端桩：概览默认只渲染问题行、搜索/筛选、预览差异、应用、单行替换、撤销按钮可用态与提示文案。
- 静态检查：`node --check`、`python -m compileall`。
- 回归：候选批次流式、批量生成、候选恢复相关桩保持通过。
