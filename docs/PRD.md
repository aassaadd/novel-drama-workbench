## 1. 背景与问题

一个人写小说时，从「文字」到「可听可看的有声剧」之间存在一条很长的断点链路：

- 写作工具只管文本，不管角色、场景、台词的语义结构；
- TTS 工具只管单段文字合成，不知道谁是说话人、情绪是什么、哪里该停顿；
- 音效与配乐需要手工在剪辑软件里对位；
- 插图和 5 秒短视频需要反复在 ComfyUI 里改提示词、导文件、再拖进时间轴；
- 每一步的中间产物都散落在不同目录，改一句台词就要重跑全链路。

本产品把这条链路收进一个本地工作台：**以「设定库 + 小说正文 + 导演脚本」为三层唯一数据源，向上提供写作与校对界面，向下把配音、音效、配图、短视频统一编排成可断点续跑的 GPU 任务队列，最终混音/合成导出有声剧成片。**

v2 的核心判断：用户的实际创作顺序是「先设定 → 再写小说 → 同步产出有声剧标注（导演脚本）→ 分别配音/配图/配视频 → 合成」，所以工作台不是一个线性流水线，而是**七个相对独立的工具共享同一套设定与正文**。工具可单独运行、单独重跑，彼此只通过落盘数据与任务队列交互。

## 2. 目标用户与使用场景

### 2.1 目标用户

| 用户 | 特征 | 核心诉求 |
| --- | --- | --- |
| 独立作者（主用户） | 单人写长篇/中篇，自己有 Mac + 一张 GPU，本机已装 omlx 与 ComfyUI | 一个人从设定走到成片，不想学剪辑软件 |
| 有声内容创作者 | 已有文本，想快速做分角色有声剧 | 多角色音色稳定、可克隆指定声音、时间轴可校对 |
| 同人/短篇创作者 | 篇幅短、更新快，追求产出速度 | 一键批处理，能接受默认参数 |

**明确只服务单机单人场景**：不做多租户、不做在线协作、不做云端渲染。

### 2.2 典型场景

1. **从零做一章有声剧**：设定工坊填世界观/大纲/角色/音色 → 小说工具按大纲续写第 1 章（可中途给思路）→ 同步生成导演脚本（谁说的、什么音效、什么画面、什么动画）→ 配音工具批量合成 → 图像工具对每个画位抽 4 张选 1 张 → 视频工具对 1~2 个高潮点生成 5 秒视频 → 合成导出 MP4。
2. **只重写一段**：小说工具里改写某段 → 系统按锚点定位到受影响的最小元素集 → 只重跑这几行的配音与相关画面，其余复用。
3. **改角色音色**：给某角色换一套「愤怒」情绪变体 → 只重跑该角色该情绪的行，台词文本与图像不动。
4. **只出音频**：跳过配图与视频，导出 MP3 + 字幕，用于播客平台。
5. **只做配音**：已有别人写好的正文，只跑导演脚本 + 配音两个工具。
6. **批量夜间渲染**：晚上把整部作品的配音/配图/视频排进串行队列，第二天看队列结果与失败项。

### 2.3 非目标场景

- 不做多人实时协作编辑；
- 不做视频剪辑器（没有多轨自由拖拽、特效、调色、转场库）；
- 不做发行/上架/分发；
- 不训练或微调模型；
- 不自带图像/视频模型（统一调用本机 ComfyUI），不做模型下载与权重管理。

## 3. 产品目标与成功指标

| 目标 | 指标（MVP 验收用） |
| --- | --- |
| 一条链路跑通 | 一个 3000 字章节，不打开任何其他软件，导出带配音/音效/配图/1 段视频的成片 |
| 设定可复用 | 一份设定同时供给小说、配音、图像三个工具，改设定后下游能明确标出需重算的范围 |
| 可恢复 | 任意一步中断（关程序、断电、ComfyUI 崩溃）后重跑，不重复烧 GPU，已完成产物复用 |
| 可校对 | 台词表里能改说话人、情绪、变体、停顿，改完整章重跑时间正确 |
| 音色稳定 | 同一角色同一情绪始终用同一音色变体；全篇复用同一份 `voice_clone_prompt`，无漂移 |
| 可替换 | 换 TTS/写作引擎只改配置与适配器实现，上层数据与时间轴不变 |
| 不抢卡 | 七类 GPU 任务串行，与 ComfyUI 队列互斥；omlx 不自动卸载，按策略显式卸载 |

## 4. 核心流程（v2 七工具）

流程与数据对象一一对应，箭头左侧是用户动作，右侧是落盘的数据。

```
[1] 设定工坊   settings/bible.json（世界观/大纲/文风/连续性）
                characters.json（角色 + 状态卡）  voices.json（音色 → 变体）
     │  settings_revision
     ├──────────────┬────────────────┬─────────────────┐
     ▼              ▼                ▼                 ▼
[2] 小说生成    [3] 导演脚本      [4] 配音          [5] 图像 / [6] 视频
 chapters/*.json  scripts/*.json   assets/voice/...  assets/image|video/...
 （正文+块+摘要） （镜头/台词/音效   （按变体+切块）   （抽卡候选 → 选中）
                    画面/动画/静音）
     │              │                │                 │
     └──────────────┴────────────────┴─────────────────┘
                                  ▼
                        [7] 合成导出  timelines/ + exports/
```

### 4.1 各工具的输入、输出与失败处理

| 工具 | 输入 | 输出 | 失败处理 |
| --- | --- | --- | --- |
| 设定工坊 | 用户录入、导入 txt/md、可选模型辅助 | 设定库 + 角色表 + 音色库 | 校验失败拒绝落盘并指出字段；`settings_revision` 不递增 |
| 小说生成 | 设定库快照、大纲节点、前文摘要、续写思路 | 正文 + 段落块 + 章节摘要 + 续写会话记录 | 生成失败保留原文；超预算时裁剪日志明确；中断后可继续 |
| 导演脚本 | 正文、设定库、角色表 | 镜头/台词/音效/画面/动画/静音/转场 + 锚点 | 未识别说话人标 `chr_unknown`；锚点孤儿进待处理列表，不阻塞其他元素 |
| 配音 | 台词行、音色变体、切块参数 | 分块 wav + 行级实测时长 | 单行失败只标该行；缺情绪变体走默认变体 + warning；授权未确认禁止克隆合成 |
| 图像 | 画面元素、角色外貌、ComfyUI 模板 | N 个候选 png + 选中项 | 单候选失败不影响同批；ComfyUI 不可达给可操作错误 |
| 视频 | 动画元素、选中图（i2v 首帧）、5 秒上限 | N 个候选 mp4 + 选中项 | 失败回退静态图；超时按任务级 timeout |
| 合成导出 | 脚本、选中产物、时间轴 | MP4/MP3/WAV/SRT/manifest | 产物缺失用占位或跳过并记 warning；失败可只重跑混音 |

### 4.2 关键产品规则

- **三层真相**：设定库、小说正文、导演脚本是源；音频、图片、视频、时间轴、成片全部可重建。
- **文本是唯一真相**：任何产物都不是手工编辑的唯一副本；改文后按锚点定位最小重算范围。
- **估算 → 实测**：未合成时用「字数/语速」估算时长，合成后替换为实测时长，并触发受影响段落的时间轴重算。
- **增量优先**：以「实体 + 版本号 + 参数哈希（含变体 ID）」做幂等键，输入没变就不重跑。
- **单卡串行**：七类 GPU 任务进同一队列，跨进程用锁文件与 ComfyUI 互斥。
- **旁白是一等公民**：旁白可绑定独立音色，与角色台词分别排版与合成。
- **显式停顿**：Qwen3-TTS 无 SSML，停顿必须由导演脚本的静音事件显式表达，不靠标点碰运气。
- **抽卡可回退**：选中即写入时间轴，未选中保留 7 天；换选不重新生成。

## 5. 用户故事

优先级：P0 = MVP 必须；P1 = MVP 后第一轮；P2 = 后置。按工具分组。

### 5.1 P0（MVP）

| # | 工具 | 用户故事 | 验收标准 |
| --- | --- | --- | --- |
| US-01 | 通用 | 作为作者，我要新建工程并写入标题、简介、类型、语言 | 生成 `project.json`，可被 CLI 与界面读取 |
| US-02 | 设定 | 我要录入世界观、时代、地点、规则、专有名词，作为全书约束 | 落盘 `settings/bible.json`；`settings_revision` 递增 |
| US-03 | 设定 | 我要建大纲（幕 → 章 → beat），并能给 beat 标关键转折 | 大纲可增删改；续写可引用 beat |
| US-04 | 设定 | 我要维护角色卡（姓名、别名、定位、性格、说话风格、外貌、当前状态） | 角色跨章节复用；状态卡可更新 |
| US-05 | 设定 | 我要建音色库：9 个预设可直接引用，也能用 3 秒以上参考音频克隆，并按情绪准备多套变体 | 克隆未确认授权不能创建；变体有试听与缓存状态 |
| US-06 | 小说 | 我要按大纲自动续写，也能给一段续写思路让它接着写 | 每次续写落一条 `continuations`；角色名/称谓与设定一致 |
| US-07 | 小说 | 我要改写指定区间，系统告诉我哪些下游产物需要重算 | 改写后给出受影响行/图/视频清单，不自动全量重跑 |
| US-08 | 脚本 | 我要从正文生成导演脚本：谁说的、什么音效、什么画面、什么动画、怎么转场 | 每行有说话人与锚点；每镜头有转场；脚本通过 schema 校验 |
| US-09 | 脚本 | 我要在脚本里校对说话人、情绪、停顿、提示词，并能跳回正文对应位置 | 双向跳转可用；孤儿锚点有专门列表 |
| US-10 | 配音 | 我要批量合成整章，并单行/按角色/按情绪重录 | 每行有状态、实测时长、所用变体；失败行可单独重试 |
| US-11 | 配音 | 我要在缺情绪变体时被明确告知降级到默认变体 | 台词表显示 warning，不静默降级 |
| US-12 | 图像 | 我要对每个画位一次生成 N 张并挑选一张进入时间轴 | 候选追加不覆盖；选中项可在时间轴预览；未选中 7 天后过期 |
| US-13 | 视频 | 我要在个别段落生成最长 5 秒的视频（文生视频或以选中图为首帧） | 时长强制 ≤5 秒；失败回退静态图 |
| US-14 | 合成 | 我要生成时间轴、试听、微调起止与音量，并导出 MP4/MP3/SRT | 时间轴含语音/音效/音乐/图像/视频轨；可重复导出 |
| US-15 | 通用 | 我要看到串行渲染队列并能重试、取消、按工具筛选 | 状态真实；失败有错误码与可操作原因 |
| US-16 | 通用 | 我要在断点后继续，不重复消耗 GPU | 重跑只执行输入变了的任务；幂等键可查 |

## 6. MVP 边界

**MVP 要做（M0~M7 全绿）**

- 单机、单用户、单工程目录的工程管理；
- 设定库（世界观/大纲/角色/音色变体）的完整数据与编辑能力，且被小说、配音、图像三个工具共享；
- 小说：分章正文、续写会话（给思路 / 按大纲）、章节摘要、写指定区间；
- 导演脚本：镜头/台词/音效/画面/动画/静音/转场 + 锚点，可人工编辑与增量重算；
- 配音：Qwen3-TTS 1.7B 适配、音色变体与情绪映射、切块合成、单句/批量/重录；
- 图像/视频：ComfyUI 网关、抽卡与选片、5 秒上限、失败回退；
- 串行 GPU 队列、断点续跑、失败重试、幂等、omlx 显式卸载；
- 时间轴生成、混音导出（音频 + 视频两种）；
- 页面：设定工坊、小说、导演脚本、配音、图像、视频、合成、渲染队列；
- CLI 覆盖各工具与全流水线。

**MVP 不做**

| 不做项 | 原因 |
| --- | --- |
| 自带/内置图像视频模型 | 统一走本机 ComfyUI |
| 模型下载与权重管理 | 写作交给 omlx、配音用已部署的 Qwen3-TTS |
| 自由视频剪辑（转场库、特效、调色、多轨拖拽） | 超出「自动成片」范围，交给专业软件 |
| 多人协作与云同步 | 单机产品定位 |
| 模型训练/微调 | 只做推理调用；克隆为零样本，不训练 |
| 计费、账号、权限体系 | 本地单用户 |
| 移动端 | 桌面工作台 |
| 向量检索/嵌入库 | 首版用关键词 + 角色名 + 章节摘要维持一致性，避免额外依赖 |

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 本地优先 | 默认零外网依赖；只有显式配置的云端适配器才允许出网 |
| 数据可迁移 | 工程为纯文件（JSON + 媒体），可整体拷贝、可进 git（媒体走忽略规则） |
| 可恢复 | 进程被杀后队列状态可从磁盘恢复；运行中任务重启后标记为「中断」并可重跑 |
| 幂等 | 同一幂等键重复执行不产生重复产物；抽卡按 seed + params_hash 去重 |
| 串行 | 同一时刻最多一个 GPU 任务；与 ComfyUI 共用同一把锁；omlx 不自动卸载，按策略显式卸载 |
| 内存约束 | omlx 内存天花板 29.48 GB，双模型同时加载会超限；调度须避免文本与 ComfyUI 同时占卡 |
| 可观测 | 每个任务有状态、耗时、尝试次数、错误码、日志路径；音色漂移可查所用变体 |
| 健壮性 | 单行/单图/单候选失败不阻塞整章；降级路径明确（视频→图，音效→静音，情绪变体→默认变体） |
| 可维护 | 单文件 ≤ 1500 行；适配层与业务层解耦；函数中文注释 |
| 资源 | 48GB 内存机器可跑；长任务可后台执行不阻塞界面 |

## 8. 里程碑与验收口径（v2 按工具重排）

| 里程碑 | 内容 | 怎么算完成 |
| --- | --- | --- |
| **M0 地基** | 工程/章节/角色/台词数据、队列与锁、CLI、schema 校验、omlx 适配器 | 现有冒烟测试通过；omlx 自检「服务可达 / 模型存在 / 最小对话」通过 |
| **M1 设定工坊** | 设定库、大纲、角色卡、音色库与变体、版本与快照 | 新建工程 → 录入世界观与 3 个角色 → 建 2 个音色（1 预设 1 克隆占位）→ 重启数据完整；导出设定快照 JSON；schema 校验通过 |
| **M2 小说生成** | 正文、续写会话、按大纲续写、章节摘要、设定注入 | 给定大纲与续写思路，生成 ≥1000 字且角色名/称谓与设定一致；生成 `synopsis`；中断后续写不重复；超预算有裁剪日志 |
| **M3 导演脚本** | 从正文生成镜头/台词/音效/画面/动画/转场、锚点、人工编辑、增量重算 | 一章 ≥3 个镜头，每行有说话人与锚点；改一句话只重算该行；删除一行时锚定音效降级并告警；脚本通过 schema 校验 |
| **M4 配音** | Qwen3-TTS 适配、音色变体与情绪映射、切块合成、单句/批量/重录、实测时长回填 | 整章行全部 `ready` 且有实测时长；长行切成 15~30 秒块且拼接无明显断点；同角色同情绪始终同一变体；缺情绪变体有降级 warning；换变体只重跑受影响行；授权未确认的克隆变体无法合成 |
| **M5 图像** | 画面元素到 ComfyUI、角色外貌拼装、抽卡与选片、候选保留期 | 每个画面抽 4 张、可选中 1 张进入时间轴；提示词含角色外貌；候选过期清理生效；ComfyUI 不可达时报可操作错误 |
| **M6 视频** | 动画元素、i2v 首帧、5 秒上限、抽卡、回退静态图 | 至少 1 段 ≤5 秒视频进入时间轴；i2v 使用选中图；失败自动回退静态图；带音轨时按 `audio_policy` 处理 |

**依赖**：M2 依赖 M1；M3 依赖 M1/M2；M4/M5/M6 可并行（都依赖 M3）；M7 依赖 M4~M6 至少各有产物，允许缺失时降级。
